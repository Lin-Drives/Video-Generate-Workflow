# 本地渲染说明

本文记录当前渲染器的使用方式与实现配置。通用制作步骤见 [新选题 AI 执行规范](新选题制作流程.md)，交付检查见 [视频验收标准](视频验收标准.md)。单条视频的角色参考、提示词、外形要求和镜头设计，由 AI 写入对应制作包或选题文档。

## 1. 当前实现与运行前检查

当前入口为 [render.sh](../render.sh)，制作逻辑位于 [work/generate.py](../work/generate.py)。运行环境为 macOS，需要 Python 3、Pillow、FFmpeg 和 ffprobe。需要生成配音时，还需可调用的 Edge TTS 运行环境及网络连接。

当前脚本内含“机器人怎么看见世界”选题的口播、英文字幕、素材列表和片头片尾文案。AI 在切换选题前必须逐项核对并更新，避免把更改输出文件名误当作切换内容。

| 配置项 | 当前实现 | 使用要求 |
| --- | --- | --- |
| 口播与镜头 | `sections` | 与本次定稿脚本及逐镜头表一致 |
| 英文字幕 | `english_subtitles` | 与中文意群逐项对应 |
| 分镜图 | `gpt_asset_dir` 与 `gpt_assets`，当前目录为 `assets/ow12/` | 核对实际文件、顺序与审核结果 |
| 片头片尾 | `title_card` 调用中的文案，素材列表首尾图片 | 更换选题时同步核对文案和图片 |
| 配音缓存 | `work/build/<镜头号>-<意群号>.mp3` | 复用前核对实际内容、音色、语速和版本 |
| 自动写入文档 | `outputs/分镜提示词-感知与视觉.md` | 运行前核对目标路径和已有人工修改，调整生成目标或内容以保护已有工作 |

生成的新配音与中间文件会写入 `work/build/`，同名文件可能被替换。AI 应先确认本次使用的版本及需要保留的源资产。

## 2. 渲染命令与配置

使用已核对的分镜图，生成配音并渲染当前配置。

```bash
USE_EXISTING_IMAGES=1 ./render.sh
```

图片与配音均已生成且内容核对一致时，可复用缓存重新合成。

```bash
REUSE_AUDIO=1 USE_EXISTING_IMAGES=1 ./render.sh
```

`REUSE_AUDIO=1` 会复用存在的逐意群配音文件，缺失的文件仍会调用 Edge TTS 生成。修改脚本、音色或语速后，AI 必须重新生成受影响配音并校验，不能只根据缓存文件名判断可复用。

| 环境变量 | 用途 |
| --- | --- |
| `OUTPUT_BASENAME` | 设置 MP4 与 SRT 的输出文件名 |
| `TTS_VOICE` | 设置 Edge TTS 音色 |
| `EDGE_TTS_RATE` | 设置配音语速 |
| `EDGE_TTS_PYTHONPATH` | 指定 Edge TTS 模块所在的运行环境路径 |
| `USE_EXISTING_IMAGES=1` | 使用并检查当前配置中的已有分镜图 |
| `REUSE_AUDIO=1` | 复用已存在且经内容核对的配音缓存 |

当前 `GENERATE_IMAGES=1` 会提示先完成外部生图审核并终止渲染。AI 需按本次选题准备、审核素材后再使用已有图片模式。

当前入口直接生成 MP4、同名 SRT 和媒体参数记录。封面、标题、事实核查与验收报告由对应制作步骤产出，并在制作包中关联。

## 3. 字幕制作规范

当前脚本将字幕烧录到画面，并同步导出可编辑的双语 SRT。AI 应复用以下已采用的排版规则，任务另有明确要求时记录新的约定并验证。

- 断句以完整问句、句子或意群为优先，过长时在合适的标点处拆分，避免孤立词。
- 当前中文字体为 `/System/Library/Fonts/Hiragino Sans GB.ttc` 的 W6 字重，英文使用 Arial。更换字体后检查简体中文字形和标点。
- 保留句内中文标点，画面与 SRT 均移除每条字幕末尾的标点。
- 英文逐条对应中文意群，置于中文正下方，字号小于中文，与中文和口播使用同一时间段。
- 按验收标准检查全部字幕、最长行及易遮挡位置，记录中文、标点、英文、行距和画面遮挡的检查结果。

视频与 SRT 同名，IINA 可自动加载外挂字幕，也可在播放器的字幕菜单中手动选择。视频本身已烧录字幕，播放时按实际需要选择外挂字幕的显示方式。

## 4. 片头、片尾与二次编辑

当前实现的片头为 3.5 秒，片尾为 5 秒，分别使用素材列表的第一张和最后一张图。两者带静音 AAC 音轨以便拼接，SRT 从片头结束后开始计时。具体文案和画面随选题更新。

导出的 MP4 已合成画面、声音与字幕。使用剪辑软件时若需分别调整各元素，应从源资产重新组织轨道，或更新源文件后重新渲染。当前脚本不直接导出多轨剪辑工程。
