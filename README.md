# 机器人工程解读视频 MVP

本项目用于在本地制作中文横版机器人工程解读视频，覆盖选题研究、脚本、分镜、素材、配音、字幕、合成与验收。MVP 的目标是跑通一条可交付、可检查的视频生产链路，默认单条 1～2 分钟，具体要求以任务约定为准。

## 工作流总览

```mermaid
flowchart LR
    A[任务边界] --> B[研究与事实核查]
    B --> C[脚本与分镜]
    C --> D[素材准备]
    D --> E[配音与字幕]
    E --> F[完整试排与剪辑准入检查]
    F --> G[正式合成]
    G --> H[验收与交付]
```

每条视频的主体、视觉风格、素材方式和具体参数，由 AI 根据任务要求在对应制作包中确定并记录。

## 创作者任务入口

下达任务时，说明想讲的选题或问题，以及希望交付选题建议、脚本还是完整视频。目标观众、参考样片、必须保留的信息和特殊限制可一并提供，已有约定会自动沿用。

例如可以直接说“做一条解释机器人如何判断能否安全通行的视频，沿用上一条的观众、时长和风格，完成到可交付成片。”

AI 负责检索、核查、脚本、分镜、素材准备、试排、检查与制作包维护。创作者在核心方向、首次风格、授权或规定的人工审核事项上作决定，AI 会集中提交具体方案和依据。

## AI 执行入口

- [新选题 AI 执行规范](docs/新选题制作流程.md)规定各阶段的动作、通过条件与异常处理。
- [选题制作包模板](docs/templates/选题制作包.md)由 AI 填写和维护，记录每条视频的资料、事实、脚本、素材及版本。
- [视频验收标准](docs/视频验收标准.md)规定自主完成的范围、检查证据与交付条件。

AI 持续推进到用户要求的终点。正式剪辑前必须通过准入检查，交付前必须完成对应验收。

## 本地使用

当前制作环境为 macOS，使用 Python、FFmpeg 和配音工具。依赖、命令、字幕排版与当前渲染器配置见 [本地渲染说明](docs/本地渲染说明.md)。

先按该说明核对本次脚本、素材与配音配置，再运行渲染入口。

```bash
./render.sh
```

当前渲染器仍包含既有选题的固定内容，切换选题时需要同步调整制作配置。渲染后的媒体参数检查是完整验收的一部分。

## 文件组织与修改

- `docs/` 保存通用执行规范、验收标准、模板及工具使用说明。
- `outputs/` 保存各选题制作文档与交付结果，新选题由制作包统一关联相关文件。
- `assets/` 保存素材，`work/` 保存制作脚本与中间文件。

MP4 可导入剪辑软件继续编辑。需要修改文字、配音或画面时，优先更新对应源文件并重新合成，时长发生变化后同步校正字幕时间轴并复验。
